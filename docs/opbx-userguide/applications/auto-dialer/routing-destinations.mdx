# Campaign Routing

Every campaign has one **routing destination**. When a callee answers, Cloudonix connects the call there. A campaign can route to an **AI assistant**, an **AI load balancer**, or **Hangup**.

## Purpose

Choose the routing destination to decide who talks to the people your campaign calls.

## Prerequisites

- The destination exists in your organization: an [AI assistant](/modules/ai-assistants) or an [AI load balancer](/modules/ai-load-balancers) with active members.
- A campaign in **Draft** or **Paused** status. See [Managing Campaigns](/applications/auto-dialer/campaigns).

## Set the destination

1. Open the campaign form, **Basic Info** tab.
2. Under **Routing Destination**, choose the type.
3. Under **Select Destination**, choose the assistant or load balancer. Hangup needs no selection.
4. Save.

The campaign form has no **Disconnect** or "Destination unavailable" choice: a campaign is always routed to one of the three types below.

## Destination types

| Type | What the callee reaches | Typical use |
|------|-------------------------|-------------|
| AI Assistant | One AI assistant, over SIP or WebSocket depending on how the assistant is set up | A single assistant handles the campaign |
| AI Load Balancer | One of the load balancer's active assistants, picked by its strategy, with failover to the next one | Higher volume, redundancy |
| Hangup | The call is ended as soon as it is answered | Testing the dialer, schedule and rates without using an assistant |

### AI assistant over SIP

The call is dialed to the assistant's service. If the assistant has an AI-assistant extension with a service URL, that URL (with its token and parameters) is used; otherwise the provider and the assistant's phone number are used. If neither is configured, the call is hung up.

### AI assistant over WebSocket

The call audio is streamed to the provider's WebSocket address, built from the provider's URL template with the call's details filled in.

### AI load balancer

OPBX asks the load balancer for an assistant according to its strategy, considering only **active** members whose assistant is **active**. It also gives Cloudonix a follow-through address: if that assistant fails (busy, no answer and so on), the next assistant is tried. If no member is available, the call is hung up.

## Passing list data to the assistant

The **Full Name**, **Batch Identifier** and **metadata columns** you mapped when uploading the [distribution list](/applications/auto-dialer/distribution-lists) are stored with each number. The metadata is handed to the assistant with each call:

| Assistant type | How metadata is sent |
|----------------|---------------------|
| SIP | As SIP headers named `X-<column>`, for example `X-company: Example Inc` |
| WebSocket | As stream parameters named after the column |
| Test (dummy) assistant | As comments in the call instructions |

The metadata is kept when a load balancer fails over to another assistant. Numbers without metadata send none.

## What happens if the destination is missing

The destination is checked when the call is placed, not when you save the campaign. If the assistant or load balancer no longer exists, belongs to another organization, or (for a load balancer) has no available member, the callee answers and the call is **hung up at once**. Check the campaign's routing before you start it.

## Deleting a destination that a campaign uses

An AI assistant or AI load balancer that a campaign routes to cannot be deleted. The delete is refused and the **Cannot delete: still in use** dialog lists the campaign. Change the campaign's routing (pause it first if it is running), then delete again. Archived and completed campaigns count too.

## Call recording

With **Record Calls** on (Advanced tab), Cloudonix records each call of the campaign. See [Recordings](/modules/recordings) for who can play recordings.

## Troubleshooting

| Symptom | Likely cause | What to do |
|---------|--------------|-----------|
| Callees answer and the line drops at once | Routing is Hangup, or the destination is missing or has no available member | Check the campaign's routing and the assistant's or load balancer's status |
| Callees answer and the line drops after about 30 seconds | Voicemail detection with "If Detection Unclear = Hang up" | See [Answering Machine Detection](/applications/auto-dialer/answering-machine-detection) |
| The assistant does not receive the lead's details | The columns were not mapped as metadata, or the assistant ignores them | Re-upload with the columns ticked as metadata; check the assistant's header or parameter handling |
