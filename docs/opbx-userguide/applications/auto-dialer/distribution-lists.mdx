# Distribution Lists

A distribution list is the set of phone numbers a campaign dials. Each entry has a phone number and, optionally, a name, a batch identifier and extra metadata columns that are passed to the AI assistant on the call.

## Purpose

Use **Distribution Lists** to:

- create a list and upload numbers from a CSV file;
- see each number's status, attempts and last call;
- assign a list to a campaign, or take it back;
- copy, download, archive or delete a list.

## Prerequisites

- You are the **Owner** or a **PBX Admin**.
- A CSV file with one column of phone numbers (with or without a header row).

## The Distribution Lists page

Open **Auto Dialer → Distribution Lists**. Each row shows the name, status, version, number of destinations, the assigned campaign (or an **Assign Campaign** button) and the creation date. Only the latest version of each list is shown.

- **Search** filters by name. The **status filter** defaults to All (except Archived); **All Statuses** also lists archived lists, and **Archived** shows only those.
- **Example CSV** downloads a sample file.
- **Create List** opens the create dialog.
- The row menu offers **View Details**, **Upload Destinations**, **Copy List**, **View Errors**, **Delete** and **Archive**, each only when the list's status allows it (see [List statuses](#list-statuses)).

## Create a list and upload numbers

1. Click **Create List**.
2. Enter a **Name** (required, up to 255 characters) and an optional **Description** (up to 1000 characters). Click **Create List**. The list is saved as **Draft**.
3. Open the row menu and choose **Upload Destinations**.
4. Choose the CSV file (`.csv`, up to 50 MB) and click **Continue to Mapping**.
5. Map the columns:

| Mapping | Required | Meaning |
|---------|----------|---------|
| Phone Number | Yes | The number to dial |
| Full Name | No | Shown in the list and passed to the assistant |
| Batch Identifier | No | A label to group numbers, for example `batch-a` |
| Metadata columns | No, any number | Every ticked column is stored per number and passed to the assistant |

6. Check the preview (first 5 rows) and click **Start Upload**.

The file is processed in the background and the list shows **Processing**. When it finishes, the list is **Ready** if at least one number was valid, or **Failed** if none was. Invalid rows are counted and, on a Failed list, listed under **View Errors**.

### CSV format

```csv
phone_number,name,batch_identifier,company
+12025550140,Liam Foster,batch-a,Example Inc
+12025550141,Olivia Reed,batch-a,Example LLC
2025550142,Noah Bennett,batch-b,Example Co
```

- With **File has a header row** on, the first row holds the column names you map. With it off, every row is data and the columns are named `column_1`, `column_2`, and so on.
- Numbers are checked with the international phone-number rules and stored in E.164 format. A number without a leading `+` is read as a **US** number, so `2025550142` becomes `+12025550142`.
- The same number twice in one file is kept once.
- Blank rows and rows with an empty phone cell are skipped.

### Large files

A list holds at most **100,000** numbers. A file with more rows is split automatically: the first part goes into your list and each further part into a new list named "*name* (Part 2)", "(Part 3)" and so on.

## List statuses

| Status | Meaning | Upload | Assign | Copy | Archive |
|--------|---------|:------:|:------:|:----:|:-------:|
| Draft | Created, no numbers yet | Yes (adds) | No | No | No |
| Pending | Waiting to be re-processed | Yes (adds) | No | No | No |
| Processing | Upload being processed | No | No | No | No |
| Ready | Has valid numbers, not assigned | Replaces (see below) | Yes | Yes | Yes |
| Failed | No valid number, or processing failed | Yes (adds) | No | No | Delete instead |
| In Use | Assigned to a campaign | No | No | Yes | No |
| Used | The campaign finished with it | Replaces | No | Yes | Only after you unassign it |
| Archived | Kept for history | No | No | Yes | No |

### Replacing the numbers of a Ready or Used list

On a list's detail page, **Upload** on a Ready or Used list **replaces** its numbers (the dialog's button reads **Create Version & Upload**): the existing numbers are backed up on the server, removed, and the new file is processed into the same list with its version number increased by one. Download the list first if you need its current numbers and statuses.

## Assign a list to a campaign

1. On a **Ready** list's row, click **Assign Campaign**.
2. Choose the campaign. Only campaigns that are **Draft**, **Paused**, or **Active but outside their schedule window** are offered.
3. Confirm.

The list becomes **In Use**. The campaign's status does not change: a **Draft** campaign stays Draft until you start it (or auto-start does). A campaign that is currently dialing is refused: "Pause the campaign first, then assign the list."

## Take a list back from a campaign

Click the unassign icon next to the campaign name on the list row. This works only while **every number is still pending with zero attempts**; otherwise the icon is disabled with "Cannot unassign: some destinations have been dialed". The list returns to **Ready**. The campaign's status is not changed.

## The list detail page

Click a list name. The header has **Refresh**, **Upload**, **Copy**, **Download**, **Archive** and **Delete**. **Delete** is shown only when the list is not assigned to a campaign; for an assigned list **Archive** is disabled and explains that you must unassign first. Cards show the total and valid or invalid numbers, the connection rate, the average call duration and the total dial attempts. When the list is assigned, a card shows the campaign and the assignment date.

Tabs:

| Tab | Shown when | Content |
|-----|-----------|---------|
| Destinations | Always | Phone number, name, batch, metadata (hover to see), status, attempts, last call, duration. Search by number and filter by status |
| Version History | The list has versions | Every version of the list |
| Validation Errors | The list is Failed | The rejected rows and why |
| Upload Info | A file was uploaded | The original file name and counts |

On the Destinations tab:

- **Reset Dial Attempts** (per row, or for the selected rows) sets the number back to pending with zero attempts and clears its last result, so it is dialed again.
- **Reset Pending Entries** sets every number that is still pending back to zero attempts and clears its retry time.

## Copy a list

1. Choose **Copy List** (row menu) or **Copy** (detail page).
2. Enter a new name. It must be unique among your lists that are not archived.

The copy is a new, unassigned **Ready** list with the same numbers, names, batches and metadata, all reset to pending with zero attempts. Use it to call the same audience again with another campaign.

## Download a list

**Download** on the detail page gives a CSV with `phone_number`, `name`, `batch_identifier`, `metadata` (JSON), `status` and `dial_attempts`.

## Archive a list

Choose **Archive** and confirm. Allowed for **Ready** and **Used** lists that are **not assigned to a campaign**. Archiving an assigned list is refused with a message naming the campaign; unassign the list first. An archived list is hidden by the default filter (choose **Archived** or **All Statuses** to see it) and can still be copied.

## Delete a list

Choose **Delete** and confirm with **Permanently Delete**. The list and all its numbers are removed.

| Who | Can delete |
|-----|-----------|
| Owner | Any list that is not assigned to a campaign |
| PBX Admin | **Failed** lists only |

**Delete** is offered only for lists that are not assigned to a campaign. If the server is asked to delete an assigned list anyway, it refuses and names the campaign. Unassign the list first, then delete it.

A PBX Admin may see **Delete** on other lists in the row menu, but the server refuses it. Use **Archive** for lists that were dialed.

## Common errors

| Message (summary) | What it means | What to do |
|-------------------|---------------|-----------|
| CSV must contain a column mapped to phone_number | The phone column was not mapped | Map the phone column (use the header-row switch to match your file) |
| Cannot upload to list in status: In Use | The list is assigned | Unassign it, or copy it and upload to the copy |
| List is not ready for assignment | The list is not Ready | Wait for processing, or fix a Failed upload |
| Cannot assign list … because it is currently running. Pause the campaign first | The campaign is dialing | Pause the campaign, assign, then resume |
| Cannot unassign list: some destinations have already been dialed | Calls were made from the list | Leave it, or copy the list |
| A list with this name already exists | Copy name in use | Choose another name |
| Batch would exceed maximum list size of 100000 | Adding numbers through the API would pass the limit | Use another list |
