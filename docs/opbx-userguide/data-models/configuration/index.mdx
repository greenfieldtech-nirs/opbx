# Configuration Reference

This page documents the environment variables and configuration values used by OPBX.

## Environment Variables

### Core Application

| Variable | Default | Description |
|----------|---------|-------------|
| `APP_NAME` | `OPBX - Open Source Business PBX` | Application name |
| `APP_ENV` | `production` | Environment mode |
| `APP_KEY` | — | Encryption key. Generate with `php artisan key:generate` |
| `APP_DEBUG` | `false` | Enable debug mode |
| `APP_URL` | `https://your-domain.com` | Base URL |
| `APP_PORT` | `80` | Host port for Nginx |
| `APP_LOCALE` | `en` | Default locale |

### Application Mode

| Variable | Default | Description |
|----------|---------|-------------|
| `OPBX_APPLICATION_MODE` | `development` | `development` or `production` (SaaS) |
| `OPBX_APPLICATION_WEBHOOK_BASEURL` | — | Application-level webhook base URL |

### Database

| Variable | Default | Description |
|----------|---------|-------------|
| `DB_CONNECTION` | `mysql` | Database driver |
| `DB_HOST` | `mysql` | Database host |
| `DB_PORT` | `3306` | Database port |
| `DB_DATABASE` | `opbx` | Database name |
| `DB_USERNAME` | `opbx` | Database user |
| `DB_PASSWORD` | — | Database password |
| `DB_ROOT_PASSWORD` | — | MySQL root password |
| `DB_EXPOSE_PORT` | — | Expose MySQL port to host (dev only) |

### Redis

| Variable | Default | Description |
|----------|---------|-------------|
| `REDIS_CLIENT` | `phpredis` | PHP Redis client |
| `REDIS_HOST` | `redis` | Redis host |
| `REDIS_PORT` | `6379` | Redis port |
| `REDIS_PASSWORD` | — | Redis password |
| `REDIS_DB` | `0` | Default database |
| `REDIS_EXPOSE_PORT` | — | Expose Redis port to host (dev only) |

### Session / Sanctum

| Variable | Default | Description |
|----------|---------|-------------|
| `SESSION_DRIVER` | `redis` | Session storage |
| `SESSION_LIFETIME` | `120` | Session lifetime (minutes) |
| `SANCTUM_STATEFUL_DOMAINS` | `localhost:3000,127.0.0.1:3000` | Cookie auth domains |
| `SANCTUM_EXPIRATION` | `1440` | Token expiration (minutes) |

### Broadcasting / WebSockets

| Variable | Default | Description |

| `PUSHER_APP_KEY` | `pbxappkey` | Soketi app key |
| `PUSHER_APP_SECRET` | — | Soketi app secret |
| `PUSHER_HOST` | `soketi` | Soketi host |
| `PUSHER_PORT` | `6001` | Soketi port |
| `PUSHER_SCHEME` | `http` | |
| `SOKETI_PORT` | `6001` | Host port for Soketi |
| `SOKETI_METRICS_PORT` | `9601` | Host port for Soketi metrics |

### Frontend (Vite)

| `FRONTEND_PORT` | `3000` | Host port for Vite dev server |
| `FRONTEND_URL` | `http://localhost:3000` | |

| `VITE_WS_HOST` | `localhost` | WebSocket host |
| `VITE_WS_PORT` | `6001` | WebSocket port |
| `VITE_WS_SCHEME` | `http` | WebSocket scheme |

### MinIO / S3 Storage

| Variable | Default | Description |
|----------|---------|-------------|
| `MINIO_ACCESS_KEY` | `minioadmin` | MinIO root user |
| `MINIO_SECRET_KEY` | `minioadmin` | MinIO root password |
| `MINIO_REGION` | `us-east-1` | |
| `MINIO_BUCKET` | `recordings` | Default bucket |
| `MINIO_ENDPOINT` | `http://minio:9000` | |

| `MINIO_EXPOSE_PORT` | — | Expose MinIO API port (dev only) |
| `MINIO_CONSOLE_EXPOSE_PORT` | — | Expose MinIO console port (dev only) |

### Cloudonix CPaaS

| Variable | Default | Description |
|----------|---------|-------------|
| `CLOUDONIX_API_BASE_URL` | `https://api.cloudonix.io` | Cloudonix API base URL |
| `CLOUDONIX_API_TIMEOUT` | `30` | API timeout |
| `CLOUDONIX_SIP_SERVER` | `sip.cloudonix.io` | SIP server |

Per-organization credentials are stored in `cloudonix_settings`.

### Webhooks / Rate Limiting

| Variable | Default | Description |
|----------|---------|-------------|
| `RATE_LIMIT_API` | `60` | API requests per minute |
| `RATE_LIMIT_WEBHOOKS` | `100` | Webhook requests per minute |
| `RATE_LIMIT_VOICE` | `1000` | Voice requests per minute |
| `RATE_LIMIT_SENSITIVE` | `10` | Sensitive operations per minute |
| `RATE_LIMIT_SENSITIVE_ADMIN` | `60` | Admin sensitive operations |
| `RATE_LIMIT_AUTH` | `5` | Auth attempts per minute |
| `CLOUDONIX_CDR_AUTH_KEY` | — | Optional CDR auth key |

### Circuit Breaker

| `CIRCUIT_BREAKER_CLOUDONIX_RETRY_AFTER` | `60` | Retry after (seconds) |

### Dialer Worker

| Variable | Default | Description |

### Transactional Email

| Variable | Default | Description |

| `EMAIL_TRACK_OPENS` | `true` | |
| `EMAIL_TRACK_CLICKS` | `true` | |

## Health Check Endpoints

| Endpoint | Purpose |
|----------|---------|
| `/api/health` | Public API health |
| `/api/storage/health` | Storage health (auth required) |
| `/api/websocket/health` | WebSocket health (auth required) |
| `/webhooks/health` | Dialer worker health |
| `/health` (amd-worker:8083) | AMD worker health |
