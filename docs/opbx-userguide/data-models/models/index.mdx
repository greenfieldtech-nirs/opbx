# Database Models

OPBX uses Laravel Eloquent models. Most models are scoped by `organization_id` through `OrganizationScope`. Platform admin models are not tenant-scoped.

## Model Reference Pages

- [AutoDialerCampaign](/opbx/data-models/models/auto-dialer-campaign) — Campaign configuration

## Tenancy Notes

- Models with `#[ScopedBy([OrganizationScope::class])]` are automatically filtered by the authenticated user's organization.
- Webhook handlers and platform admin operations must use `OrganizationScope::bypass()` when querying tenant-scoped models.
- `PlatformAuditLog`, `PlatformHealthCheck` and `EmailLog` are not tenant-scoped.
- Rows of several tables are pruned daily by retention settings; call records are tiered instead. See [Data Retention](/opbx/data-models/configuration/index#data-retention).
