# AutoDialerCampaign Model

The `AutoDialerCampaign` model represents an outbound dialing campaign with configuration for routing, scheduling, rate limiting, AMD actions, and Caller ID pooling.

**Table:** `auto_dialer_campaigns`  
**Model:** `App\Models\AutoDialerCampaign`  
**Resource:** `App\Http\Resources\AutoDialerCampaignResource`

## Indexes

| Index | Columns |
|-------|---------|
| `adc_org_status_idx` | `organization_id`, `status` |
| `adc_org_auto_start_idx` | `organization_id`, `auto_start`, `status` |
| `adc_dates_idx` | `start_date`, `end_date` |
| `auto_dialer_campaigns_routing_destination_id_foreign` | `routing_destination_id` |

`organization_id` references `organizations` with `ON DELETE CASCADE`. `routing_destination_id` has no foreign key constraint: it points to an AI assistant or an AI load balancer depending on `routing_destination_type`.

### Belongs To

```php

campaign.aiLoadBalancer() → AiAssistantLoadBalancer (routing_destination_id, when routing to a load balancer)
```

### Has Many

```php

  - With pivot: weight, with timestamps
```

## Caller ID Pooling

### Enable Pool Mode

```php
$campaign->update([
    'caller_id_pool_enabled' => true,
    'caller_id_strategy' => 'round_robin', // or 'random', 'least_recently_used'
]);
```

### Assign Caller IDs

```php
$syncData = [
    $didId1 => ['weight' => 1],
    $didId2 => ['weight' => 1],
];
$campaign->callerIds()->sync($syncData);
```

## Methods

### Scopes

```php
AutoDialerCampaign::forOrganization($orgId)
AutoDialerCampaign::active()
AutoDialerCampaign::paused()
AutoDialerCampaign::draft()
AutoDialerCampaign::runnable() // Active, with start_date/end_date within one day of today (coarse pre-filter; isRunnable() does the exact, timezone-aware check)
```

### Business Logic

```php
$campaign->isRunnable(): bool
$campaign->getProgressPercentage(): int
$campaign->getApiIntervalMilliseconds(): float
$campaign->hasValidCac(): bool
$campaign->hasValidCps(): bool
$campaign->hasList(): bool
$campaign->canStart(): bool
$campaign->canPause(): bool
$campaign->canAcceptList(): bool
$campaign->getPendingCount(): int          // destinations with status pending
$campaign->getRoutingDestinationLabel(): string
$campaign->clearRedisKeys(): void          // deletes dialer:cac:{id}:active and campaign:{id}:caller_id_index on the dialer Redis
```

`isRunnable()` evaluates the current time in the campaign's `timezone` and checks the date range and the `schedule` time ranges for today. `getApiIntervalMilliseconds()` returns `1000 / calls_per_second`. `hasValidCac()` and `hasValidCps()` check the `MIN_CAC`/`MAX_CAC` (1-50) and `MIN_CPS`/`MAX_CPS` (1-30) constants.
