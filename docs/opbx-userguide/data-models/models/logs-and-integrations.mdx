# Call Logs, Delivery Logs and Ad Platform Integrations

Legacy call logs, webhook delivery logs, and ad-platform credentials.

## CallLog

Legacy per-call log. The `call-initiated` webhook dispatches `ProcessInboundCallJob`, which creates the row (`firstOrCreate` by `call_id`); the `call-status` and CDR webhooks update it if it exists. Call history in the UI comes from [call detail records](/opbx/data-models/models/call-detail-record).

**Table:** `call_logs`  
**Model:** `App\Models\CallLog`  
**Tenant scoped:** yes (`OrganizationScope`)

| Column | Type | Nullable | Default | Description |
|--------|------|----------|---------|-------------|
| `id` | bigint unsigned | No | auto | Primary key |
| `organization_id` | bigint unsigned | No | - | Tenant. Foreign key to `organizations`, on delete cascade |
| `call_id` | varchar(255) | No | - | Cloudonix call ID |
| `direction` | enum | No | `inbound` | Inbound or outbound. Values: `inbound`, `outbound` |
| `from_number` | varchar(20) | No | - | Caller |
| `to_number` | varchar(20) | No | - | Called number |
| `did_id` | bigint unsigned | Yes | null | Number called. Foreign key to `did_numbers`, on delete set null |
| `extension_id` | bigint unsigned | Yes | null | Extension. Foreign key to `extensions`, on delete set null |
| `ring_group_id` | bigint unsigned | Yes | null | Ring group. Foreign key to `ring_groups`, on delete set null |
| `status` | enum | No | `initiated` | Call state. Values: `initiated`, `ringing`, `answered`, `completed`, `busy`, `no_answer`, `failed` (cast to `CallStatus`) |
| `initiated_at` | timestamp | Yes | null | Start |
| `answered_at` | timestamp | Yes | null | Answer |
| `ended_at` | timestamp | Yes | null | End |
| `duration` | int | Yes | null | Seconds |
| `recording_url` | varchar(255) | Yes | null | Recording URL |
| `cloudonix_cdr` | json | Yes | null | CDR payload |
| `created_at` | timestamp | Yes | null |  |
| `updated_at` | timestamp | Yes | null |  |

**Indexes**

- `call_logs_call_id_index`: `call_id`
- `call_logs_call_id_unique` (unique): `call_id`
- `call_logs_did_id_foreign`: `did_id`
- `call_logs_extension_id_foreign`: `extension_id`
- `call_logs_from_number_created_at_index`: `from_number`, `created_at`
- `call_logs_organization_id_created_at_index`: `organization_id`, `created_at`
- `call_logs_ring_group_id_foreign`: `ring_group_id`
- `call_logs_status_index`: `status`
- `call_logs_to_number_created_at_index`: `to_number`, `created_at`

**Casts:** `cloudonix_cdr` (array)  

**Relationships**

```php
$callLog->organization() → Organization (organization_id) [BelongsTo]
$callLog->didNumber() → DidNumber (did_id) [BelongsTo]
$callLog->extension() → Extension (extension_id) [BelongsTo]
$callLog->ringGroup() → RingGroup (ring_group_id) [BelongsTo]
```

**Methods:** `isActive()`, `isCompleted()`  

## CallNotificationLog

One delivery attempt of a [call notification](/opbx/data-models/models/call-notifications-settings) webhook.

**Table:** `call_notification_logs`  
**Model:** `App\Models\CallNotificationLog`  
**Tenant scoped:** yes (`OrganizationScope`)  
**Traits:** `PrunesByRetention`

| Column | Type | Nullable | Default | Description |
|--------|------|----------|---------|-------------|
| `id` | bigint unsigned | No | auto | Primary key |
| `organization_id` | bigint unsigned | No | - | Tenant. Foreign key to `organizations`, on delete cascade |
| `call_session_token` | varchar(255) | No | - | Cloudonix session token |
| `event_id` | char(36) | No | - | Event UUID |
| `event_type` | varchar(50) | No | - | Event (`new`, `ringing`, ...) |
| `status` | varchar(50) | No | - | Call status in the event |
| `webhook_url` | varchar(2048) | No | - | Destination URL |
| `request_payload` | json | No | - | JSON sent |
| `request_headers` | json | Yes | null | Headers sent |
| `request_body` | text | Yes | null | Body sent |
| `response_status_code` | smallint unsigned | Yes | null | HTTP status |
| `response_body` | text | Yes | null | Response body |
| `response_headers` | json | Yes | null | Response headers |
| `response_time_ms` | int unsigned | Yes | null | Response time |
| `attempt_number` | tinyint unsigned | No | `1` | Attempt number |
| `is_success` | boolean | No | `false` | 2xx response |
| `error_message` | text | Yes | null | Error |
| `created_at` | timestamp | No | - |  |

**Indexes**

- `call_notification_logs_call_session_token_index`: `call_session_token`
- `call_notification_logs_event_id_index`: `event_id`
- `call_notification_logs_organization_id_created_at_index`: `organization_id`, `created_at`

**Casts:** `request_payload` (array), `request_headers` (array), `response_headers` (array)  

**Relationships**

```php
$callNotificationLog->organization() → Organization (organization_id) [BelongsTo]
```

**Scopes:** `forOrganization()`, `forSession()`, `successful()`, `failed()`, `recent()`  
**Methods:** `markAsSuccess()`, `markAsFailed()`  

Rows whose `created_at` is older than `RETENTION_CALL_NOTIFICATION_LOGS_DAYS` (default 90) are deleted daily by `model:prune`.

## CallTrackingNotificationLog

One delivery attempt of a [call tracking notification](/opbx/data-models/models/call-tracking-notification-settings) webhook.

**Table:** `call_tracking_notification_logs`  
**Model:** `App\Models\CallTrackingNotificationLog`  
**Tenant scoped:** yes (`OrganizationScope`)

| Column | Type | Nullable | Default | Description |
|--------|------|----------|---------|-------------|
| `id` | bigint unsigned | No | auto | Primary key |
| `organization_id` | bigint unsigned | No | - | Tenant. Foreign key to `organizations`, on delete cascade |
| `call_tracking_campaign_id` | bigint unsigned | No | - | Campaign. Foreign key to `call_tracking_campaigns`, on delete cascade |
| `call_id` | varchar(255) | Yes | null | Cloudonix call ID |
| `event_id` | varchar(255) | No | - | Event ID |
| `event_type` | varchar(100) | No | - | Event (`call.received`, ...) |
| `webhook_url` | varchar(2048) | No | - | Destination URL |
| `request_payload` | json | No | - | JSON sent |
| `request_headers` | json | Yes | null | Headers sent; `Authorization` is stored as `***REDACTED***` |
| `response_body` | text | Yes | null | Response body |
| `response_headers` | json | Yes | null | Response headers |
| `response_status_code` | smallint unsigned | Yes | null | HTTP status |
| `response_time_ms` | int unsigned | Yes | null | Response time |
| `is_success` | boolean | No | `false` | 2xx response |
| `attempt_number` | tinyint unsigned | No | `1` | Attempt number |
| `error_message` | varchar(1024) | Yes | null | Error |
| `created_at` | timestamp | Yes | null |  |
| `updated_at` | timestamp | Yes | null |  |

**Indexes**

- `ct_notif_logs_campaign_fk`: `call_tracking_campaign_id`
- `ct_notif_logs_event_id_idx`: `event_id`
- `ct_notif_logs_org_campaign_created_idx`: `organization_id`, `call_tracking_campaign_id`, `created_at`

**Casts:** `request_payload` (array), `request_headers` (array), `response_headers` (array)  

**Relationships**

```php
$callTrackingNotificationLog->organization() → Organization (organization_id) [BelongsTo]
$callTrackingNotificationLog->campaign() → CallTrackingCampaign (call_tracking_campaign_id) [BelongsTo]
```


This table is not pruned by `model:prune`.

## CallTrackingAdPlatformIntegration

Per-organization credentials for uploading call-tracking conversions to Google Ads and Meta.

**Table:** `call_tracking_ad_platform_integrations`  
**Model:** `App\Models\CallTrackingAdPlatformIntegration`  
**Tenant scoped:** yes (`OrganizationScope`)

| Column | Type | Nullable | Default | Description |
|--------|------|----------|---------|-------------|
| `id` | bigint unsigned | No | auto | Primary key |
| `organization_id` | bigint unsigned | No | - | Tenant. Foreign key to `organizations`, on delete cascade |
| `google_ads_enabled` | boolean | No | `false` | Upload conversions to Google Ads |
| `google_ads_developer_token` | text | Yes | null | Developer token (`encrypted` cast) |
| `google_ads_refresh_token` | text | Yes | null | OAuth refresh token (`encrypted` cast) |
| `google_ads_customer_id` | varchar(255) | Yes | null | Customer ID (`encrypted` cast) |
| `google_ads_conversion_action_resource_name` | varchar(1024) | Yes | null | Conversion action resource name (`encrypted` cast) |
| `meta_enabled` | boolean | No | `false` | Upload conversions to Meta |
| `meta_pixel_id` | varchar(255) | Yes | null | Pixel ID (`encrypted` cast) |
| `meta_access_token` | text | Yes | null | Access token (`encrypted` cast) |
| `created_at` | timestamp | Yes | null |  |
| `updated_at` | timestamp | Yes | null |  |

**Indexes**

- `call_tracking_ad_platform_integrations_organization_id_unique` (unique): `organization_id`


**Relationships**

```php
$callTrackingAdPlatformIntegration->organization() → Organization (organization_id) [BelongsTo]
```

**Scopes:** `forOrganization()`
