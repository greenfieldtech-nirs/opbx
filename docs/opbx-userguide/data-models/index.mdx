## Recently Added

### Call Record Tiers and Platform Status (2026-10)

| Change | Purpose |
|--------|---------|
| `archived_call_detail_records` | Warm tier for call records 6-12 months old |
| `direction` on `call_detail_records` | Call direction, copied from the session update |
| `platform_health_checks` | Platform Status history |
| `unavailable` destination type | Added to every routing destination enum column |

The unused `VoiceAgent` model was removed; AI assistants are `AiAssistant`.

### Caller ID Pooling (v2026.04)

New models supporting multiple Caller IDs per campaign:

| Model | Purpose |
|-------|---------|
| `AutoDialerCampaignCallerId` | Pivot table linking campaigns to DIDs |
| `AutoDialerCallerIdStat` | Tracks call statistics per Caller ID |

See [Auto Dialer Campaigns](/opbx/modules/auto-dialer-campaigns) for usage documentation.
