# Data Models Overview

This section provides comprehensive documentation of the data structures in OPBX.

## Categories

### [Database Models](/opbx/data-models/models/index)

Complete reference of all Eloquent models including:

- Table structure and columns
- Relationships
- Scopes and mutators
- Business logic methods

### [Enumerations](/opbx/data-models/enums/index)

All PHP enums used throughout the application:

## Key Models by Module

### Auto Dialer

- [AutoDialerCampaign](/opbx/data-models/models/auto-dialer-campaign) — Campaign configuration
- [AutoDialerCampaignCallerId](/opbx/data-models/models/auto-dialer-campaign-caller-id) — Caller ID pool entries
- [AutoDialerCallerIdStat](/opbx/data-models/models/auto-dialer-caller-id-stat) — Per-Caller ID statistics
- AutoDialerList (`App\Models\AutoDialerList`) — Distribution lists
- AutoDialerDestination (`App\Models\AutoDialerDestination`) — List destinations

### Core PBX

- Extension (`App\Models\Extension`) — PBX extensions
- DidNumber (`App\Models\DidNumber`) — Phone numbers
- RingGroup (`App\Models\RingGroup`) — Ring group configuration
- IvrMenu (`App\Models\IvrMenu`) — IVR menu structure
- BusinessHoursSchedule (`App\Models\BusinessHoursSchedule`) — Business hours
- CallQueue (`App\Models\CallQueue`) — Call queues (live state is in the ACD worker)

### AI Integration

- AiAssistant (`App\Models\AiAssistant`) — AI assistant configuration
- AiAssistantLoadBalancer (`App\Models\AiAssistantLoadBalancer`) — Load balancer setup

### Users & Organizations

- User (`App\Models\User`) — User accounts
- Organization (`App\Models\Organization`) — Multi-tenant organizations
- [CloudonixSettings](/opbx/data-models/models/cloudonix-settings) — Cloudonix credentials per org

### Call & Logging

- [CallDetailRecord](/opbx/data-models/models/call-detail-record) — CDR from Cloudonix, with the warm archive table
- [SessionUpdate](/opbx/data-models/models/session-updates) — Real-time session events
- [CallNotificationsSettings](/opbx/data-models/models/call-notifications-settings) — Webhook notification config
- CallNotificationLog (`App\Models\CallNotificationLog`) — Notification delivery log
- [EmailLog](/opbx/data-models/models/email-logs) — Transactional email log
- [PlatformAuditLog](/opbx/data-models/models/platform-audit-logs) — Cross-tenant audit trail
- [PlatformHealthCheck](/opbx/data-models/models/platform-health-check) — Platform Status history

### Call Tracking

- [CallTrackingCampaign](/opbx/data-models/models/call-tracking-campaign) — Marketing campaign attribution
- [CallTrackingNumber](/opbx/data-models/models/call-tracking-number) — DID-to-campaign assignment
- [CallTrackingSession](/opbx/data-models/models/call-tracking-session) — Attributed call session
- [CallTrackingNotificationSettings](/opbx/data-models/models/call-tracking-notification-settings) — Per-campaign webhook settings
- CallTrackingNotificationLog (`App\Models\CallTrackingNotificationLog`) — Notification delivery log
- CallTrackingAdPlatformIntegration (`App\Models\CallTrackingAdPlatformIntegration`) — Google Ads / Meta settings

### Security

- InboundBlacklist (`App\Models\InboundBlacklist`) — Blocked caller patterns
- OutboundWhitelist (`App\Models\OutboundWhitelist`) — Outbound routing rules
- BlockedCallLog (`App\Models\BlockedCallLog`) — Log of blocked calls

## Recently Added

### Call Record Tiers and Platform Status (2026-10)

| Change | Purpose |
|--------|---------|
| `archived_call_detail_records` | Warm tier for call records 6-12 months old |
| `direction` on `call_detail_records` | Call direction, copied from the session update |
| `platform_health_checks` | Platform Status history |
| `unavailable` destination type | Added to every routing destination enum column |

The unused `VoiceAgent` model was removed; AI assistants are `AiAssistant`.

### Caller ID Pooling (v2026.04)

New models supporting multiple Caller IDs per campaign:

| Model | Purpose |
|-------|---------|
| `AutoDialerCampaignCallerId` | Pivot table linking campaigns to DIDs |
| `AutoDialerCallerIdStat` | Tracks call statistics per Caller ID |

See [Auto Dialer Campaigns](/opbx/modules/auto-dialer-campaigns) for usage documentation.
