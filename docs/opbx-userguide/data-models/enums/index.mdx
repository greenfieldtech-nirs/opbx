## Using Enums

```php
use App\Enums\CampaignStatus;

// From value
$status = CampaignStatus::from('active');

// Safely
$status = CampaignStatus::tryFrom($value);

// All cases
$all = CampaignStatus::cases();

// Value and label
$value = $status->value;
$label = $status->label();

// Validation
Rule::enum(CampaignStatus::class)
```
