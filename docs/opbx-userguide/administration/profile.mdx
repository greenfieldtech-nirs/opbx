# Profile

The Profile page is where every signed-in user manages their own account: name, email and contact details, password, and linked social accounts. The Owner also edits the organization's name and time zone here. Users who have a PBX extension also see their **Extension Number** on the Profile Information card.

Open it from the user menu: click your name at the top right and choose **Profile**.

## Permissions

| Section | Owner | PBX Admin | PBX User | Reporter | Supervisor |
|---------|:-----:|:---------:|:--------:|:--------:|:----------:|
| Organization Details: view | Yes | Yes | Yes | Yes | Yes |
| Organization Details: edit | Yes | No | No | No | No |
| Profile Information: edit your own | Yes | Yes | Yes | Yes | Yes |
| Change Password | Yes | Yes | Yes | Yes | Yes |
| Linked Accounts (when Auth0 is configured) | Yes | Yes | Yes | Yes | Yes |

For everyone except the Owner, the Organization Details fields are disabled and the card says "Only organization owners can edit these settings".

## Organization Details (Owner)

| Field | Limits | Notes |
|-------|--------|-------|
| Organization Name | 2 to 255 characters | The name shown for the organization |
| Timezone | A valid time zone; the list has 56 entries grouped by Africa, Americas, Asia, Australia, Europe, Pacific and UTC | The organization's default time zone |

Click **Save Organization**. If nothing changed, the toast says "Organization is already up to date".

Business-hours schedules and auto-dialer campaigns have their own time zone setting; changing the organization's time zone does not change them.

## Profile Information

| Field | Required | Limits | Notes |
|-------|----------|--------|-------|
| Full Name | Yes | 2 to 255 characters | |
| Email Address | Yes | Valid email, up to 255 characters, not used by any other account | Used to sign in. If you link social accounts, they must use the same email |
| Phone Number (Optional) | No | Up to 20 characters | |
| Country (Optional) | No | Picked from a searchable list | |
| Street Address (Optional) | No | Up to 500 characters | |
| City (Optional) | No | Up to 100 characters | |
| State/Province (Optional) | No | Up to 100 characters | |
| Postal Code (Optional) | No | Up to 20 characters | |
| Role | — | — | Shown as a badge. Nobody can change their own role here; ask an Owner (the Owner sees "You cannot change your own role") |

Click **Save Profile**. Only changed fields are sent; if nothing changed, the toast says "Profile is already up to date". After a save the form shows the values the server stored.

:::note Your own role
Nobody can change their own role, so the profile shows it as a badge for every role. To change roles, use the [Users](/modules/user-management) page for other users.
:::

## Change Password

1. Enter your **Current Password**.
2. Enter the **New Password** and repeat it in **Confirm New Password**. Under the confirmation field, "Passwords match" or "Passwords don't match" updates as you type.
3. Optionally click **Generate Strong Password**. It fills both fields with a random 16-character password and shows it with a copy button: "Make sure to save this password securely before submitting the form".
4. Click **Change Password**.

The new password must have at least 8 characters, upper- and lower-case letters, a number and a symbol. The form only checks the length; the other rules are checked when you submit.

On success every API token of your account is revoked, so scripts or other sessions that use a token must sign in again.

| Message | Meaning |
|---------|---------|
| The current password is incorrect. | Wrong current password |
| Password confirmation does not match. | The two new-password fields differ |
| The new password must contain… | A missing upper/lower case letter, number or symbol |

{/* SCREENSHOT: profile-change-password — Change Password card with a generated password shown with its copy button and "Passwords match" under the confirmation field */}

Accounts created through a social sign-in or an invitation have no password you know. Use **Linked Accounts** to sign in, or ask an administrator to set a password on the Users page.

## Linked Accounts

When Auth0 sign-in is configured for the deployment, a **Linked Accounts** card lists each configured provider (for example Google or Microsoft):

- **Connect** sends you to the provider; sign in with the same email as your OPBX account. You come back to the profile with the provider linked.
- **Disconnect** unlinks it ("Account unlinked."). Your account and password are not affected.

See [Auth0 Syndicated Authentication](/modules/auth0-syndicated-auth) for the rules and error messages.

## Related API endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/v1/profile` | Your profile, linked accounts and organization |
| PUT | `/v1/profile` | Update your name, email and contact details |
| PUT | `/v1/profile/password` | Change your password (stricter rate limit) |
| PUT | `/v1/profile/organization` | Update the organization name and time zone (Owner; stricter rate limit) |

See the [OPBX REST API reference](https://developers.cloudonix.com/opbxRestOpenAPI) for full schemas.
