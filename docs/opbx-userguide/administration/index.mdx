# Organization Settings

This page covers the settings that apply to your own account and to your organization. The admin interface itself is explained in [Navigating the Admin Interface](/administration/navigating-the-interface).

## Where the settings are

| Page | How to open it | Who can use it |
|------|----------------|----------------|
| Profile (`/ui/profile`) | User menu, top right: **Profile** | Every signed-in user, for their own account |
| Settings (`/ui/settings`) | User menu, top right: **Settings** | Owner only |
| Users (`/ui/users`) | Sidebar, PBX Configuration: **Users** | Owner and PBX Admin |
| Platform Management | Sidebar, Platform Management section | Platform managers only. See [Platform Management](/administration/platform-management) |

:::tip
For the full Cloudonix setup workflow, see [Cloudonix Setup](/installation/cloudonix-setup). For local webhook development with ngrok, see the [Installation guide](/installation).
:::

## Profile

Every signed-in user can change their own:

| Field | Limit |
|-------|-------|
| Name | Up to 255 characters |
| Email | Unique within the organization |
| Phone | Up to 20 characters |
| Street address | Up to 500 characters |
| City, state or province, country | Up to 100 characters each |
| Postal code | Up to 20 characters |

To change the password, enter the **current password** first, then the new one.

The Owner can also change the organization's name and details, on the Settings page. Other users cannot.

## Cloudonix Integration

The Cloudonix integration connects your organization to the Cloudonix CPaaS for voice services. It is an **Owner-only** page.

| Field | Meaning |
|-------|---------|
| Domain UUID | Your Cloudonix domain UUID |
| Domain API key | Cloudonix API key with access to the domain |
| Requests API key | Key used to authenticate voice webhooks. It can be generated from this page |
| Webhook base URL | Public URL where Cloudonix can reach OPBX |
| No-answer timeout | Seconds to wait before treating a call as unanswered |
| Recording format | `mp3` or `wav` |

Use **Validate** to check the credentials against Cloudonix before you save.

{/* SCREENSHOT: settings-cloudonix — Settings page, Cloudonix Integration section with the domain fields filled in (values masked) and the Validate button */}

Saving the settings updates the domain profile in Cloudonix and creates or updates the OPBX voice application that Cloudonix calls. Check the result on the Settings page and in [Call Logs](/modules/call-logs) after a test call.
