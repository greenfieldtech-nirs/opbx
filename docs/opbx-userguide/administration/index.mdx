# Organization Settings

This page tells you where the settings that apply to your own account and to your organization live. The admin interface itself is explained in [Navigating the Admin Interface](/opbx/administration/navigating-the-interface).

## Where the settings are

| Page | How to open it | Who can use it | What it holds |
|------|----------------|----------------|---------------|
| Profile (`/ui/profile`) | User menu, top right: **Profile** | Every signed-in user, for their own account | Your name, email, contact details, password and linked social accounts. The Owner also renames the organization and sets its time zone here. See [Profile](/opbx/administration/profile) |
| Settings (`/ui/settings`) | User menu, top right: **Settings** | Owner only | The Cloudonix integration: domain credentials, webhook key, webhook base URL, no-answer timeout, call recording, recording format and the embedded dialer's allowed domains. See [Settings](/opbx/modules/settings) |
| Users (`/ui/users`) | Sidebar, PBX Configuration: **Users** | Owner and PBX Admin | The organization's users and roles. See [User Management](/opbx/modules/user-management) |
| API Keys (`/ui/api-keys`) | Sidebar, Analytics: **API Keys** | Owner only | Keys for scripts and integrations. See [API Keys](/opbx/modules/api-keys) |
| Call Notifications (`/ui/call-notifications`) | Sidebar, Analytics: **Call Notifications** | Owner and PBX Admin | The organization's call-event webhook. See [Call Notifications](/opbx/modules/call-notifications) |
| Platform Management | Sidebar, Platform Management section | Platform managers only | Cross-tenant administration. See [Platform Management](/opbx/administration/platform-management) |

Other roles do not see the **Settings** item in the user menu. If they open `/ui/settings` directly, they get an "Access denied" toast and are sent back to the dashboard.

:::tip
For the first-time Cloudonix setup, see [Cloudonix Setup](/opbx/installation/cloudonix-setup). For local webhook development with ngrok, see the [Installation guide](/opbx/installation#webhooks-not-received-in-local-development).
:::
