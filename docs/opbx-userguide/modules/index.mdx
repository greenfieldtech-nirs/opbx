# OPBX Modules

OPBX provides a comprehensive set of modules for managing your business phone system. Each module handles a specific aspect of PBX functionality.

## Available Modules

| Module | Description |
|--------|-------------|
| [User Management](/modules/user-management) | Create and manage user accounts with role-based access control |
| [Supervisors](/modules/supervisors) | Let a supervisor watch and coach live calls of the users and ring groups assigned to them |
| [Extensions](/modules/extensions) | Configure phone extensions with SIP credentials and Cloudonix sync |
| [Phone Numbers](/modules/phone-numbers) | Manage DID numbers and configure inbound call routing |
| [Trunks](/modules/trunks) | Manage the inbound and outbound SIP trunks held in Cloudonix |
| [Ring Groups](/modules/ring-groups) | Distribute incoming calls across groups of extensions |
| [Call Queues](/modules/call-queues) | Stateful call distribution with waiting callers, agent states, and queue statistics |
| [IVR Menus](/modules/ivr-menus) | Build interactive voice response menus with digit-based navigation |
| [Business Hours](/modules/business-hours) | Route calls based on time of day with weekly schedules and holidays |
| [Conference Rooms](/modules/conference-rooms) | Set up multi-party conference bridges with PIN protection |
| [AI Assistants](/modules/ai-assistants) | Configure AI-powered voice agents |
| [AI Load Balancers](/modules/ai-load-balancers) | Distribute calls across multiple AI providers |
| [Call Logs](/modules/call-logs) | View and export call detail records |
| [Live Calls](/modules/live-calls) | Monitor, disconnect, and coach active calls in real time |
| [Reporting](/modules/reporting) | Dashboard, call logs and live monitoring at a glance |
| [Web Phone](/modules/web-phone) | In-browser softphone for placing, receiving, and coaching calls |
| [Embedded Dialer](/modules/embedded-dialer) | Embed a user's Web Phone in a third-party website with one script snippet |
| [Call Tracking Campaigns](/modules/call-tracking-campaigns) | Attribute inbound calls to marketing campaigns and sources |
| [Call Tracking DNI](/modules/call-tracking-dni) | Dynamic number insertion for websites |
| [Call Tracking Analytics](/modules/call-tracking-analytics) | Campaign performance, conversions, and exports |
| [Call Notifications](/modules/call-notifications) | Configure webhook notifications for call events |
| [Recordings](/modules/recordings) | Upload and manage audio files for IVR prompts and announcements |
| [Inbound Blacklist](/modules/inbound-blacklist) | Block unwanted inbound callers |
| [Outbound Whitelist](/modules/outbound-whitelist) | Choose which destination prefixes may be dialled, through which trunk and with which caller ID |

## Getting Started

Read [Navigating the Admin Interface](/administration/navigating-the-interface) first; it explains the sidebar, roles and the delete and Unprovisioned patterns that every module uses.

If you are setting up OPBX for the first time, we recommend configuring the modules in this order:

1. **Users** — [User Management](/modules/user-management): create accounts for your team members
2. **Extensions** — [Extensions](/modules/extensions): assign phone extensions to each user
3. **Trunks** — [Trunks](/modules/trunks): add the SIP trunks used for inbound and outbound calls, if your provider needs them
4. **Phone Numbers** — [Phone Numbers](/modules/phone-numbers): add your DID numbers and configure routing
5. **Ring Groups** — [Ring Groups](/modules/ring-groups): set up call distribution for departments
6. **Call Queues** — [Call Queues](/modules/call-queues): add queues if you need waiting callers and statistics
7. **Business Hours** — [Business Hours](/modules/business-hours): configure time-based routing rules
8. **IVR Menus** — [IVR Menus](/modules/ivr-menus): build automated phone menus for callers

Then add [Recordings](/modules/recordings) for prompts and hold music, and [Inbound Blacklist](/modules/inbound-blacklist) or [Outbound Whitelist](/modules/outbound-whitelist) for call control.

## Module Documentation Format

Each module guide is a walk-through:

- **Purpose** and **prerequisites**: what the module is for and what must exist first
- **Permissions**: which roles can see and change it
- **Create, edit and delete**: step by step, with every field and its real limits
- **What happens on save**, and the in-use check that can refuse a delete
- **Common errors**: the messages you can see and what to do
- **Related modules** and API endpoints
