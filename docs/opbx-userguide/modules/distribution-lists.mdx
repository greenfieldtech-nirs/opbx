# Distribution Lists

A distribution list holds the phone numbers an [auto-dialer campaign](/opbx/modules/auto-dialer-campaigns) dials, with an optional name, batch identifier and metadata per number. This page is the reference and the list of workflows. The step-by-step screen walk-through is [Distribution Lists](/opbx/applications/auto-dialer/distribution-lists) in the Auto Dialer guide.

## Purpose

Use this module to:

- create lists and upload numbers from CSV;
- assign a list to a campaign and take it back;
- reset numbers so they are dialed again;
- copy, download, archive and delete lists.

## Prerequisites

- **Owner** or **PBX Admin** role to change anything; **Reporter** may view.
- A CSV file with a header row and a phone-number column.

## Limits

| Item | Limit |
|------|-------|
| List name | Required, up to 255 characters |
| Description | Up to 1000 characters |
| CSV file | `.csv` or `.txt`, up to 50 MB, first row is the header |
| Numbers per list | 100,000. Larger files are split into "*name* (Part 2)", "(Part 3)" and so on |
| Numbers per API batch add | 1000 |
| Phone numbers | Validated with international numbering rules, stored as E.164. Numbers without `+` are read as US numbers. Duplicates in a file or list are skipped |
| Copy name | Unique among your lists that are not archived |

## Statuses

| Status | Meaning |
|--------|---------|
| `draft` | Created, no numbers yet |
| `pending` | Numbers removed for a re-upload, waiting to be processed |
| `processing` | An upload is being processed |
| `ready` | Has valid numbers; can be assigned |
| `failed` | No valid number, or processing failed. Errors can be viewed |
| `in_use` | Assigned to a campaign |
| `used` | A campaign has finished with it |
| `archived` | Kept for history |

A campaign can hold several lists; assigning another list adds it to the ones already assigned. Assigning a list does not change the campaign's status: a **Draft** campaign stays Draft until it is started. See [Assign a list](/opbx/applications/auto-dialer/distribution-lists#assign-a-list-to-a-campaign).

## Number statuses

| Status | Meaning |
|--------|---------|
| `pending` | Waiting to be dialed (or waiting for its retry time) |
| `dialing` | A call is being placed |
| `connected` | The call is in progress |
| `completed` | The call was answered |
| `failed` | Not reached after its attempts, or refused 3 times in a row |
| `invalid` | Not a dialable number |

## Permissions

| Action | Owner | PBX Admin | PBX User | Reporter | Supervisor |
|--------|:-----:|:---------:|:--------:|:--------:|:----------:|
| See the page, list lists and their numbers | Yes | Yes | No | Yes (read-only) | No |
| Create, upload, copy, download | Yes | Yes | No | No | No |
| Download the example CSV | Yes | Yes | No | Yes | No |
| Assign and unassign | Yes | Yes | No | No | No |
| Reset dial attempts | Yes | Yes | No | No | No |
| Archive (Ready or Used, not assigned to a campaign) | Yes | Yes | No | No | No |
| Delete a Failed list | Yes | Yes | No | No | No |
| Delete any other list | Yes | No | No | No | No |

Archiving an assigned list is refused (HTTP 422, the message names the campaign); unassign it first. The list index API takes `status=archived` for archived lists and `status=all` for every status including archived; without `status` it returns non-archived lists. Deleting removes the list completely (the list, all its numbers, their dialing records and the backup copies kept when it was re-uploaded; nothing can be restored) and asks for confirmation first. The lists split off it from a large file ("*name* (Part 2)" and so on) are deleted with it, and the confirmation says how many. A list that is assigned to a campaign, or whose parts include one that is, cannot be deleted: the delete is refused, nothing is deleted, and a dialog names the campaign (and the part). Unassign it first.

## Workflows

The Distribution Lists screens are documented step by step in the **Auto Dialer** application guide. Each workflow below says who can do it and links to the steps.

### Find a list

**Who can do this:** Owner, PBX Admin, Reporter.

Open **Auto Dialer → Distribution Lists**, type in the search box or pick a status (the default hides archived lists). See [The Distribution Lists page](/opbx/applications/auto-dialer/distribution-lists#the-distribution-lists-page).

### Download the example CSV

**Who can do this:** Owner, PBX Admin, Reporter.

Click **Example CSV** at the top of the page. The format is described in [CSV format](/opbx/applications/auto-dialer/distribution-lists#csv-format).

### Create a list and upload numbers

**Who can do this:** Owner, PBX Admin.

Click **Create List**, then **Upload Destinations** in the row menu, map the columns and click **Start Upload**. See [Create a list and upload numbers](/opbx/applications/auto-dialer/distribution-lists#create-a-list-and-upload-numbers). When processing ends the detail page confirms "Upload completed successfully".

### Replace the numbers of a list

**Who can do this:** Owner, PBX Admin. Not while the list is In Use.

Click **Upload** on the list's detail page. On a Ready or Used list this creates a new version. See [Replacing the numbers of a Ready or Used list](/opbx/applications/auto-dialer/distribution-lists#replacing-the-numbers-of-a-ready-or-used-list).

### Assign a list to a campaign

**Who can do this:** Owner, PBX Admin. The list must be Ready.

Click **Assign Campaign** on the list's row. See [Assign a list to a campaign](/opbx/applications/auto-dialer/distribution-lists#assign-a-list-to-a-campaign).

### Unassign a list from a campaign

**Who can do this:** Owner, PBX Admin. Not while the list's campaign is Active (HTTP 403, "Cannot unassign list: its campaign is active. Pause the campaign first."; pause it first), and only until the campaign has started processing the list's entries: once a number has been dialed or is no longer pending, the list stays with the campaign (HTTP 422). The same rules, codes and messages apply on the list page, on the campaign's detail page and to both API endpoints. While a list cannot be unassigned its row shows **Locked**; the hover text gives the reason.

Click the unassign icon next to the campaign name, or **Unassign** next to the list on the campaign's detail page. The campaign's other lists are not affected. The page confirms "List unassigned from campaign successfully". See [Take a list back from a campaign](/opbx/applications/auto-dialer/distribution-lists#take-a-list-back-from-a-campaign).

### View a list's numbers and results

**Who can do this:** Owner, PBX Admin, Reporter.

Click the list's name to open its detail page, then search and filter the **Destinations** tab (All Statuses, Pending, Completed, Failed or Invalid). See [The list detail page](/opbx/applications/auto-dialer/distribution-lists#the-list-detail-page). For a Failed list, **View Errors** in the row menu shows the rejected rows. The detail page's **Validation Errors** tab does not list the rows yet, and its **Download Errors CSV** button does nothing; use **View Errors** instead.

### Reset numbers so they are dialed again

**Who can do this:** Owner, PBX Admin. Reporters see the buttons, but the server refuses the change and the page shows "Failed to reset dial attempts".

On the detail page's **Destinations** tab, use **Reset Dial Attempts** on a row, select rows and click **Reset Dial Attempts (*n*)**, or click **Reset Pending Entries**. A toast reports the server's result. See [The list detail page](/opbx/applications/auto-dialer/distribution-lists#the-list-detail-page).

The **Delete** button that appears when rows are selected does not delete anything yet: it only shows "Deleting *n* destinations..." and clears the selection.

### Copy a list

**Who can do this:** Owner, PBX Admin.

Choose **Copy List** in the row menu or **Copy** on the detail page. See [Copy a list](/opbx/applications/auto-dialer/distribution-lists#copy-a-list).

### Download a list

**Who can do this:** Owner, PBX Admin. Reporters see the **Download** button, but the server refuses and the page shows "Failed to download list".

Click **Download** on the detail page. The page confirms "List downloaded successfully". See [Download a list](/opbx/applications/auto-dialer/distribution-lists#download-a-list).

### Archive a list

**Who can do this:** Owner, PBX Admin. The list must be Ready or Used and not assigned to a campaign.

Choose **Archive** in the row menu or on the detail page. The page confirms "List archived successfully" (row menu) or "List archived" (detail page). See [Archive a list](/opbx/applications/auto-dialer/distribution-lists#archive-a-list).

### Delete a list

**Who can do this:** Owner (any list not assigned to a campaign); PBX Admin (Failed lists only). The **Delete** action is hidden from everyone else.

Choose **Delete** and confirm with **Permanently Delete**. The page confirms "List deleted successfully" (row menu) or "List deleted" (detail page). See [Delete a list](/opbx/applications/auto-dialer/distribution-lists#delete-a-list).

### API-only tasks

Adding single numbers or batches of up to 1000 numbers (`destinations`, `destinations/batch`), the CSV preview and the version and validation-error endpoints have no separate button beyond those above. Use the API endpoints below.

## Key data fields

### `auto_dialer_lists`

| Column | Notes |
|--------|-------|
| `id`, `organization_id` | Key and tenant scope |
| `campaign_id` | The campaign the list is assigned to, or empty. Several lists can share one campaign |
| `name`, `description` | |
| `version_number`, `parent_list_id`, `is_latest_version` | Versioning. Only latest versions appear on the page |
| `status` | See [Statuses](#statuses) |
| `used_by_campaign_id`, `used_at` | Last assignment |
| `original_filename`, `total_rows`, `valid_rows`, `invalid_rows`, `validation_errors` | Upload results |
| `processed_at`, `archived_at` | Timestamps |

### `auto_dialer_destinations`

| Column | Notes |
|--------|-------|
| `id`, `organization_id`, `list_id` | Keys |
| `phone_number` | E.164 |
| `name`, `batch_identifier`, `metadata` | From the CSV mapping. `metadata` is passed to the AI assistant on the call |
| `status` | See [Number statuses](#number-statuses) |
| `dial_attempts`, `consecutive_initiate_failures`, `next_retry_at` | Attempts and retry timing |
| `last_dialed_at`, `last_disposition`, `last_error`, `duration`, `billsec` | Last result |
| `last_session_token`, `last_call_id`, `last_cdr_id` | Links to the call |

## Related API endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/v1/auto-dialer-campaigns/lists` | List lists (filters: `status`, `campaign_id`, `search`) |
| POST | `/v1/auto-dialer-campaigns/lists` | Create |
| GET | `/v1/auto-dialer-campaigns/lists/example-csv` | Example CSV |
| GET | `/v1/auto-dialer-campaigns/lists/{list}` | One list |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/preview-csv` | Headers and first 5 rows of a file |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/upload` | Upload a CSV with a column `mapping` |
| GET | `/v1/auto-dialer-campaigns/lists/upload-progress/{jobId}` | Upload progress |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/destinations` | Add one number |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/destinations/batch` | Add up to 1000 numbers |
| GET | `/v1/auto-dialer-campaigns/lists/{list}/destinations` | Numbers (filters: `status`, `search`) |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/destinations/{destinationId}/reset-dial-attempts` | Reset one number |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/destinations/bulk-reset-dial-attempts` | Reset selected numbers |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/reset-pending-destinations` | Reset every pending number |
| GET | `/v1/auto-dialer-campaigns/lists/{list}/versions` | Version history |
| GET | `/v1/auto-dialer-campaigns/lists/{list}/validation-errors` | Errors of a Failed list |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/copy` | Copy |
| GET | `/v1/auto-dialer-campaigns/lists/{list}/download` | CSV export |
| PATCH | `/v1/auto-dialer-campaigns/lists/{list}/archive` | Archive |
| DELETE | `/v1/auto-dialer-campaigns/lists/{list}` | Delete the list, its parts and everything stored with them (409 with a usage list while the list or a part is assigned to a campaign) |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/assign` | Assign to a campaign (`campaign_id`) |
| POST | `/v1/auto-dialer-campaigns/lists/{list}/unassign` | Take back from the campaign (403 while the campaign is active, 422 once its entries have started processing) |

**Scoped API keys** use the `distribution-lists` resource. The **MCP server** offers tools such as `list_distribution_lists`, `create_distribution_list`, `add_distribution_list_destinations`, `assign_distribution_list` and `unassign_distribution_list`. See [API Keys](/opbx/modules/api-keys) and [MCP Server](/opbx/modules/mcp-server).

See the [OPBX REST API reference](https://developers.cloudonix.com/opbxRestOpenAPI) for full schemas.
